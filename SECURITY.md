# Security policy

RichClub Explorer is research software and should not be used to process identifiable,
confidential, or regulated data in a public deployment. Network tables uploaded to a
third-party Streamlit deployment may be subject to that host's data-handling terms.

Please report security concerns privately through the maintainer's GitHub profile.
Do not open a public issue containing credentials, private data, or exploit details.

Only the latest tagged release is eligible for security fixes.
